【Chick Weight 家禽資料集－LSTM Transfer Learning 指令整理版】

整理原則：
1. main.py 只負責訓練：pre-train / without-transfer-learning / transfer-learning。
2. generate_original_metrics_from_model.py 只負責讀取既有模型並補算 original-scale metrics。
3. 若 generate_original_metrics_from_model.py 放在 notebook/ 底下，請從專案根目錄執行：
   python notebook/generate_original_metrics_from_model.py ...
4. 若已移到專案根目錄，改用：
   python generate_original_metrics_from_model.py ...

一、Stage 0：Kaggle Source 0~21 Pre-Train
============================================================

python main.py --out-dir "Chick Weight Result" \
  --train-mode pre-train \
  --source-name "Kaggle Weight vs Age of Chicks" \
  --seed 1234 \
  --nb-epochs 5000 \
  --period 3

============================================================
七、Inverse Transform 結果輸出檢查
============================================================
每次 inverse transform 後，請確認目標 out-dir 內出現：
1. metrics_original_scale.txt
2. prediction_original_scale.csv
3. original_metrics_params.json

若沒有產生，優先檢查：
1. model-path 是否真的存在。
2. dataset-path 是否有 X_train.pkl / y_train.pkl / X_test.pkl / y_test.pkl。
3. dataset-path 是否有 target_scaler.pkl。
4. period 是否與原實驗一致。
5. generate_original_metrics_from_model.py 是否從專案根目錄執行。
